 Dashboard E-Commerce / Manajemen Produk Toko Online

Aplikasi web interaktif berbasis React 19, Vite, Bootstrap, dan jQuery untuk memenuhi tugas Responsi 1 Pemrograman Fullstack UNISA Yogyakarta.
 
 Fitur Utama

-CRUD Produk: Tambah produk baru, ubah harga/data produk, dan hapus produk dari etalase.
-Pencarian Real-Time: Filter daftar produk berdasarkan nama atau kategori secara instan.
-Validasi & Format: Perhitungan diskon dan pemformatan mata uang Rupiah otomatis.

Cara Menjalankan Proyek

1.Pastikan sudah menginstal Node.js.
2.Buka terminal pada folder proyek, lalu instal dependensi dengan perintah:
```bash
npm install
```
